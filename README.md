# Ритм

Персональный трекер привычек на русском языке. Статическое приложение без установки зависимостей.

## Запуск

Из этой папки: `node server.cjs`, затем открыть http://127.0.0.1:4173.

## Возможности

- Цели: выполнение, количество, минуты; расписания по дням или N раз в неделю.
- Отметки, отмена, редактирование прошлого дня, календарь, недельная статистика и серии.
- Редактирование, архивирование и восстановление привычек.
- JSON-экспорт и восстановление резервных копий; синхронизация вкладок одного браузера.
- Адаптивный интерфейс и управление формой с клавиатуры.

## Хранение и ограничения

Данные хранятся только в localStorage текущего браузера и адреса сайта. Локальная и опубликованная версии имеют разные хранилища: переносите данные через экспорт и восстановление. Очистка данных браузера удаляет прогресс. Серверной синхронизации, аккаунтов приложения и уведомлений пока нет.

Изменения целей и расписания сохраняются как версии: дневные изменения действуют со следующего дня, недельные — со следующего понедельника. Предыдущие результаты не пересчитываются. Уже пересчитанную старой версией историю восстановить автоматически невозможно.

Недельные цели учитываются отдельно от дневного процента. В первой неполной неделе цель ограничена количеством доступных дней. Серии недельных привычек измеряются в неделях; остальных — в запланированных днях. Текущий незаконченный день/неделя не обрывает серию. При смене вида расписания начинается новая серия. Архив сохраняет отметки и исключает период паузы из плана.

При первом открытии старой версии создаётся локальная копия `ritm-before-v2`. Перед восстановлением из файла текущие данные сохраняются в `ritm-before-import`. Эти копии доступны через кнопку внизу страницы, но не заменяют скачанный файл: очистка браузера удаляет их тоже. Некорректные данные блокируют запись до восстановления, чтобы избежать их перезаписи.

## Проверки

`node --test core.test.cjs` — миграция, история целей, архив, недельные контракты, серии и валидация копий.

`node browser.test.cjs` — сценарии браузера при запущенном сервере. Нужны Playwright и Microsoft Edge. Путь к Playwright можно задать переменной `PLAYWRIGHT_MODULE`. Проверки используют отдельный временный профиль и не затрагивают пользовательские данные.

## Структура

`dist/index.html`, `dist/style.css`, `dist/refinements.css`, `dist/app.js` — интерфейс; `dist/core.js` — правила расчёта и миграция; `server.cjs` — локальный сервер.
