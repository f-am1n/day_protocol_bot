# Ритм

Персональный трекер привычек на русском языке. Статическое приложение без установки зависимостей.

## Запуск

Из этой папки: `node server.cjs`, затем открыть http://127.0.0.1:4173.

## Возможности

- Цели: выполнение, количество, минуты; расписания по дням или N раз в неделю.
- Отметки, отмена, редактирование прошлого дня, календарь, недельная статистика и серии.
- Редактирование, архивирование и восстановление привычек.
- JSON-экспорт и восстановление резервных копий; синхронизация вкладок одного браузера.
- Адаптивный интерфейс и управление формой с клавиатуры.

## Хранение и ограничения

Данные хранятся только в localStorage текущего браузера и адреса сайта. Локальная и опубликованная версии имеют разные хранилища: переносите данные через экспорт и восстановление. Очистка данных браузера удаляет прогресс. Серверной синхронизации и аккаунтов приложения пока нет. Установленное приложение на некоторых устройствах имеет отдельное хранилище: для переноса используйте экспорт и восстановление.

## Уведомления и установка

Кнопка с колокольчиком открывает время и дни напоминаний. Настройки сохраняются отдельно на каждом устройстве. Разрешение запрашивается только после нажатия «Включить уведомления»; есть тест и отключение.

Уведомления браузера работают только при открытой активной странице. Проверка выполняется каждые 30 секунд, с окном доставки 15 минут после указанного времени. Если все запланированные цели выполнены, уведомление не отправляется. Web Locks и метка дня предотвращают повтор в нескольких вкладках. В системных настройках браузера и ОС уведомления могут быть заблокированы.

Фоновый Web Push и серверный планировщик не подключены. Для закрытого сайта доступен экспорт повторяющегося события `.ics` с VALARM. Его нужно импортировать в календарь и проверить включение оповещения; поддержка импорта и сигналов зависит от календаря. Событие не знает о выполнении привычек. Изменение или отключение браузерного напоминания не меняет ранее импортированное событие.

Добавлены manifest, PNG-иконки и service worker для уведомлений и открытия сайта по нажатию. Service worker не кэширует приватные страницы и не обходит доступ к сайту. Офлайн-режим не добавлен. На iPhone/iPad уведомления веб-приложения требуют установки на главный экран в поддерживаемой версии iOS. Подсказка доступна в настройках.

Источники: [MDN Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API/Using_the_Notifications_API), [WebKit: Web Push on iOS](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

Изменения целей и расписания сохраняются как версии: дневные изменения действуют со следующего дня, недельные — со следующего понедельника. Предыдущие результаты не пересчитываются. Уже пересчитанную старой версией историю восстановить автоматически невозможно.

Недельные цели учитываются отдельно от дневного процента. В первой неполной неделе цель ограничена количеством доступных дней. Серии недельных привычек измеряются в неделях; остальных — в запланированных днях. Текущий незаконченный день/неделя не обрывает серию. При смене вида расписания начинается новая серия. Архив сохраняет отметки и исключает период паузы из плана.

При первом открытии старой версии создаётся локальная копия `ritm-before-v2`. Перед восстановлением из файла текущие данные сохраняются в `ritm-before-import`. Эти копии доступны через кнопку внизу страницы, но не заменяют скачанный файл: очистка браузера удаляет их тоже. Некорректные данные блокируют запись до восстановления, чтобы избежать их перезаписи.

## Проверки

`node --test core.test.cjs` — миграция, история целей, архив, недельные контракты, серии и валидация копий.

`node browser.test.cjs` — сценарии браузера при запущенном сервере. Нужны Playwright и Microsoft Edge. Путь к Playwright можно задать переменной `PLAYWRIGHT_MODULE`. Проверки используют отдельный временный профиль и не затрагивают пользовательские данные.

`node devices.test.cjs chromium firefox webkit` — десять размеров экранов, три раздела, диалоги, горизонтальная ориентация, крупный текст, календарный экспорт. Firefox и WebKit устанавливаются через Playwright; `PLAYWRIGHT_BROWSERS_PATH` по умолчанию указывает на `.sites-runtime/browsers`. Эмуляция браузера не заменяет проверку реального iPhone или Android.

`node reminders.test.cjs` — разрешения, регистрация реального service worker, расписание, отсутствие дублей, отключение и отказ в разрешении. Доставка системных уведомлений заменена тестовой функцией; реальных уведомлений эти тесты не отправляют.

## Структура

`dist/index.html`, `dist/style.css`, `dist/refinements.css`, `dist/app.js` — интерфейс; `dist/core.js` — правила расчёта и миграция; `server.cjs` — локальный сервер.
